# Informationssicherheit

Vorlagen für das Sicherheitskonzept und für Fragen zur Sicherheit der Software. Welche davon passen,
hängt davon ab, ob die Behörde zur Bundesverwaltung gehört und ob OPAA im eigenen Haus oder in einer
Cloud läuft.

| Dokument | Worum es geht | Gilt für |
|---|---|---|
| [Sicherheitsnachweise](sicherheitsnachweise.md) | Belege zur Sicherheit des Projekts | alle |
| [IT-Grundschutz](grundschutz-modellierung.md) | Abbildung im IT-Grundschutz des BSI | Bundesministerien verpflichtend, sonst freiwillig |
| [NIS2 in der Bundesverwaltung](nis2-bundesverwaltung.md) | Pflichten nach NIS2 | Bundesverwaltung |
| [C5 für den Cloud-Betrieb](c5-cloud-betrieb.md) | Nachweis des Cloud-Anbieters | nur bei Betrieb in einer Cloud |
| [Cyber Resilience Act](rollenklaerung-cra.md) | Rollen und Pflichten | alle |
