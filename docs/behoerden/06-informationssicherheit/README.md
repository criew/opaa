hängt davon ab, ob die Behörde zur Bundesverwaltung gehört und ob OPAA im eigenen Haus oder in einer
Cloud läuft.

| Dokument | Worum es geht | Gilt für |

| [NIS2 in der Bundesverwaltung](nis2-bundesverwaltung.md) | Pflichten nach dem NIS2-Umsetzungsgesetz und was OPAA dazu liefert | Bundesverwaltung |
