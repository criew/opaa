# Pilot und Teststellung

Vorlagen für die Erprobung vor einer Vergabe oder einem breiten Einsatz. Eine Teststellung prüft
OPAA mit eigenen Dokumenten der Behörde gegen vorher festgelegte Kriterien; ein Pilot lässt einen
begrenzten Kreis von Beschäftigten damit arbeiten. Beides kann schon mitbestimmungspflichtig sein.

| Dokument | Worum es geht |
|---|---|
| [Kurzprüfung vor dem Start](kurzpruefung.md) | Fragen an Datenschutz, Informationssicherheit und Personalvertretung |
| [Pilot-Vereinbarung](pilot-vereinbarung.md) | Rahmen eines Pilots mit Beschäftigten |
| [Teststellungsszenario](teststellungsszenario.md) | eigene Dokumente, Prüffragen, Erfolgs- und Abbruchkriterien |
| [Teststellungsvereinbarung](teststellungsvereinbarung.md) | Teststellung bei einem Dienstleister und Löschnachweis |
