# Mitbestimmung

Vorlagen für die Beteiligung des Personalrats. Ein KI-Assistent, der Daten über Beschäftigte
speichert, ist in einer Behörde in der Regel mitbestimmungspflichtig; ohne Dienstvereinbarung beginnt
meist keine Einführung. Die Dienstvereinbarung ist so gebaut, dass nicht jedes Update neu verhandelt
werden muss und der Überwachungsumfang trotzdem nicht unbemerkt wächst.

| Dokument | Worum es geht |
|---|---|
| [Dienstvereinbarung](dienstvereinbarung.md) | Mustertext mit Verboten, Stufenmodell für Updates und Anlagen zu einer festen Version |
| [Informationsmappe für den Personalrat](informationsmappe-personalrat.md) | was wer über wen sieht, mögliche und ausgeschlossene Auswertungen, Datenfluss zum Modellanbieter, Glossar |
| [Personalvertretungsrecht der Länder](personalvertretungsrecht-der-laender.md) | Gesetz und amtliche Fundstelle je Land, Arbeitsblatt für die Vorschriften zu Überwachungstechnik, Dienstvereinbarung, Nachwirkung und Sachverständigen |
