# Datenschutz

Vorlagen für die Datenschutzunterlagen, die eine Behörde vor dem Start von OPAA braucht. Die meisten
erstellt die Behörde gemeinsam mit ihrer oder ihrem Datenschutzbeauftragten.

| Dokument | Worum es geht |
|---|---|
| [Verzeichnis von Verarbeitungstätigkeiten (VVT)](verzeichnis-verarbeitungstaetigkeiten.md) | der Eintrag für OPAA im Pflichtverzeichnis aller Verarbeitungen personenbezogener Daten |
| [Datenschutz-Folgenabschätzung (DSFA)](datenschutz-folgenabschaetzung.md) | schriftliche Risikoprüfung vor dem Start, bei KI-Assistenten in der Regel nötig |
| [Technische und organisatorische Maßnahmen (TOM)](technische-und-organisatorische-massnahmen.md) | welche Schutzmaßnahmen OPAA mitbringt und welche die Behörde ergänzt |
| [Löschkonzept](loeschkonzept.md) | welche Daten wann gelöscht werden und wer die Fristen festlegt |
| [Auftragsverarbeitung (AVV)](avv-entscheidungsmatrix.md) | mit wem ein Vertrag zur Auftragsverarbeitung nötig ist, je nach Betrieb und Modellanbieter |
| [Informationspflichten](informationspflichten.md) | Text, mit dem die Beschäftigten über die Verarbeitung informiert werden |
| [Betroffenenrechte](betroffenenrechte.md) | wie Anfragen auf Auskunft, Berichtigung oder Löschung bearbeitet werden |
