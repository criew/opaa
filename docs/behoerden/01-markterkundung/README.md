# Markterkundung

Unterlagen für die Markterkundung, mit der sich eine Behörde vor einer Vergabe einen Überblick
verschafft. Sie beschreiben OPAA so, dass sich Fragebögen und Gespräche mit Dienstleistern darauf
stützen können. Das Projekt gibt selbst keine Angebote ab.
