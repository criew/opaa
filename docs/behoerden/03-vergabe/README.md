# Vergabe

Vorlagen für die Ausschreibung eines KI-Assistenten. Anforderungskatalog und Zuschlagskriterien sind
herstellerneutral und lassen sich direkt in eine Leistungsbeschreibung übernehmen; wie OPAA die
Anforderungen erfüllt, steht getrennt in der Erfüllungsmatrix.
