# Vorlagen einschalten

**Ziel:** Word-Vorlagen stehen im Katalog, und wer das Anlegerecht hat, legt neue an.
{: .kopf }

**Wer:** Systemverwaltung, „Administration → Vorlagen“
{: .kopf }

Ab Werk sind Vorlagen aus: Der Katalog zeigt keine, und niemand kann eine anlegen.

1. Unter „Administration → Vorlagen“ den Schalter „Vorlagen anbieten“ einschalten. Die Änderung
   gilt sofort auf allen Instanzen, ohne Neustart.
2. Unter [Anlegerechte vergeben](anlegerechte.md) das Recht „Vorlagen anlegen“ an Personen oder
   Gruppen geben; ab Werk hat es niemand außer der Systemverwaltung.

Ausgeschaltet verschwinden die Vorlagen aus Katalog und Spaces, gespeicherte Vorlagen bleiben
erhalten und sind nach dem Einschalten unverändert zurück. Jede Änderung steht mit altem und neuem
Wert im [Nachweisprotokoll](nachweisprotokoll-lesen.md).

**Gut zu wissen:**

- Wie eine Vorlage aufgebaut ist und welche Dateien abgelehnt werden, steht unter
  [Vorlage anlegen](../benutzer/vorlage-anlegen.md).
- Eine einzelne Vorlage sperren Sie wie einen Agenten:
  [Agent oder Vorlage sperren](agenten.md#agent-oder-vorlage-sperren).
- Ist die [Virenprüfung](virenpruefung.md) eingeschaltet, geht auch jede Vorlage vor dem Speichern
  an den Scanner.
