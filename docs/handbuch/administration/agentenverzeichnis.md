# Agentenverzeichnis einsehen

**Ziel:** Die Personalvertretung sieht, welche Agenten und Vorlagen es gibt und was sie tun, und hat eine Liste für die Anlage einer Dienstvereinbarung.
{: .kopf }

**Wer:** Recht „Agentenverzeichnis einsehen“, „Administration → Agentenverzeichnis“ oder „Verzeichnis“ in der linken Leiste
{: .kopf }

Das Verzeichnis beschreibt **Objekte, nicht Personen**. Es nennt jeden Agenten und jede Vorlage
Ihrer Organisation, auch solche, die die betrachtende Person sonst nicht sehen dürfte. Wer einen
Agenten wie oft nutzt, steht nicht darin.

| Je Agent | Je Vorlage |
|---|---|
| Name, Zweck und Anweisung | Name und Zweck |
| Namen der zugeordneten Bibliotheken, nicht ihr Inhalt | Dateiname und Platzhalter |
| Werkzeuge, Beginn (sofort oder mit Plan) und Grenzen | |
| Namen der zugeordneten Vorlagen | |
| verantwortliche Stelle, Fassung, gesperrt seit | verantwortliche Stelle, Fassung, gesperrt seit |

## Recht vergeben

Ab Werk sieht das Verzeichnis nur die Systemverwaltung.

1. „Administration → Anlegerechte“ öffnen.
2. Im Abschnitt „Wer darf das Agentenverzeichnis einsehen?“ auf „Ändern“.
3. „Nur bestimmte Gruppen und Personen“ wählen und etwa die Gruppe des Personalrats eintragen.
4. „Speichern“.

## Verzeichnis ansehen und exportieren

1. Das Verzeichnis öffnen. Oben stehen die Anzahl der Agenten und Vorlagen.
2. Eine Zeile anklicken: Die Seite zeigt den Eintrag vollständig, nur zum Lesen.
3. „Als CSV exportieren“ speichert das Verzeichnis als Tabelle mit einer Zeile je Agent und je
   Vorlage, lesbar in jeder Tabellenkalkulation.

**Gut zu wissen:**

- Jedes Ansehen und jeder Export steht mit Datum im [Nachweisprotokoll](nachweisprotokoll-lesen.md),
  auch ein abgewiesener Versuch; der Inhalt des Verzeichnisses steht dort nicht.
- Eine Sperre zeigt das Verzeichnis mit Datum, ohne den Grund. Den Grund sehen nur die
  Systemverwaltung und wer den Agenten verwaltet.
- Das Verzeichnis und sein Recht gibt es nur, solange [Agenten eingeschaltet](agenten.md) sind;
  Vorlagen erscheinen nur, solange [Vorlagen eingeschaltet](vorlagen.md) sind.
