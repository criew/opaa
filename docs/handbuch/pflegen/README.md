# Pflegen

Was zu tun hat, wer an einer Bibliothek, einem Space oder einer Gruppe eine Rolle für andere trägt:
Quellen anbinden, teilen, Metadaten setzen, einen Space pflegen. Jede Seite nennt oben, wer es darf.
