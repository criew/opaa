# Arbeiten

Was jedes Konto ab Werk kann: fragen, Belege prüfen, Chats führen, Spaces und eigene Bibliotheken
anlegen. Jede Seite ist eine Aufgabe und passt auf einen Bildschirm. Wer eine Bibliothek, einen
Space oder eine Gruppe für andere pflegt, findet das unter Pflegen.

| Aufgabe | Seite |
|---|---|

| Eine Datei an die Frage hängen oder die Frage diktieren | [Dateien anhängen und diktieren](anhaengen-und-diktieren.md) |
| Prüfen, worauf eine Antwort sich stützt | [Belege prüfen](belege-pruefen.md) |
| Eine Antwort kopieren oder einen Chat exportieren | [Antworten weitergeben](antworten-weitergeben.md) |
| Chats ordnen, archivieren und wiederfinden | [Chats verwalten](chats.md) |
| Arbeitsmittel finden und einem Space zuordnen | [Den Katalog nutzen](katalog.md) |
| Einen Space für eine Gruppe anlegen | [Einen Space anlegen](space-anlegen.md) |
| Eigene Dokumente durchsuchbar machen | [Eine Bibliothek anlegen](bibliothek-anlegen.md) |
| Die eigene Ablage beim Anbieter durchsuchen | [Eine private Bibliothek anlegen](private-bibliothek.md) |
