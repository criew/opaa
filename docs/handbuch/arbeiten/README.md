# Arbeiten

Was jedes Konto ab Werk kann: fragen, Belege prüfen, Chats führen, Spaces und eigene Bibliotheken
anlegen. Die Seiten folgen der Reihenfolge, in der man OPAA kennenlernt. Wer eine Bibliothek, einen
Space oder eine Gruppe für andere pflegt, findet das unter Pflegen.
