# Belege prüfen

> **Wer darf das:** wer die Antwort sieht, also wer den Chat führt. Ein Beleg öffnet nur Dokumente,
> die Sie lesen dürfen.

Sie sehen, auf welche Stellen sich eine Antwort stützt, und öffnen sie im Original.

1. Unter der Antwort die Schaltfläche mit dem Belegstand wählen, etwa „Belegt · 3 Stellen in
   2 Dokumenten“. Oder eine Fußnote im Text anklicken; dann ist ihre Fundstelle markiert.
2. Im Fenster „Belege dieser Antwort“ stehen die zitierten Dokumente mit Fußnoten, Titel und
   Fundort. „Nicht zitierte anzeigen“ blendet die geprüften, aber nicht verwendeten darunter ein.
3. „Dokument öffnen“ springt an die zitierte Stelle und hebt sie hervor. „Herunterladen“ speichert
   das Original.

**Der Belegstand** sagt, worauf sich die Antwort stützt, nicht, ob sie stimmt:

| Stufe | Bedeutung |
|---|---|
| „Belegt“ | jede Aussage mit einem bestätigten Beleg, jede Teilfrage gedeckt |
| „Teilweise belegt“ | auch unbestätigte Belege, eine Teilfrage ohne Fundstelle oder eine abgebrochene Antwort; der Grund steht daneben |
| „Nicht belegt“ | kein bestätigter Beleg |

OPAA glaubt dem Modell die Belege nicht, sondern prüft jeden: Hat die Antwort das zitierte Dokument
tatsächlich gesehen, und stimmen Beträge, Daten und Paragrafen im Satz mit dem Dokument überein? Ein
Beleg, der durchfällt, heißt **„Beleg nicht bestätigt“** und trägt ein Warnsymbol. Teilfragen ohne
Fundstelle nennt der Block „Ohne Fundstelle“ oben im Belegfenster mit Wortlaut.

**Wie ein Dokument öffnet:**

| Art | Ansicht |
|---|---|
| PDF | eigenes Fenster, auf der Seite der Fundstelle, Stelle farbig hervorgehoben; links das Inhaltsverzeichnis, falls das PDF eines hat |
| Markdown, Text | Textvorschau an der Fundstelle |
| Office, Tabelle, Mail | **Textfassung**: der gelesene Text ohne Layout, an der Passage; „Vorherigen Text laden“ und „Weiteren Text laden“ blättern |
| Confluence-Seite | an der Quelle; der Browser scrollt zur Stelle |
| Bild | neuer Tab |

**Hinweise im Belegfenster:**

| Hinweis | Bedeutung |
|---|---|
| „geprüft, nicht zitiert“ | lag der Antwort vor, wurde aber nicht verwendet |
| „Stand vom …“ | die Bibliothek wurde zuletzt an diesem Tag aktualisiert; der Grund und die zuständige Stelle stehen dabei |
| „ohne Angabe“ | gefunden unter einem Filter, obwohl das Dokument das gefilterte Feld nicht hat |
| „Private Quelle“ | stammt aus Ihrer [privaten Bibliothek](private-bibliothek.md); nur Sie sehen das |
| „Das Original wurde seit der Antwort geändert …“ | die Datei ist nicht mehr die zitierte Fassung |
| „Die Fundstelle wurde im Original nicht gefunden …“ | etwa bei einem Scan; die Seite öffnet ohne Markierung |

**Gut zu wissen:**

- Der Belegstand wird mit der Antwort gespeichert und zeigt beim Wiederöffnen denselben Stand.
- „In Belegen suchen“ durchsucht Titel und Fundort aller Belege, auch der ausgeblendeten.
- Belege kopieren und exportieren: [Antworten weitergeben](antworten-weitergeben.md).
