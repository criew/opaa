# Interne Gruppe pflegen

**Ziel:** Eine Gruppe wie „Projekt Bauleitplanung“, der andere Bibliotheken freigeben und die sie in Spaces aufnehmen.
{: .kopf }

**Wer:** *Verantwortliche* der Gruppe und die Systemverwaltung; anlegen nur mit Anlegerecht
{: .kopf }

1. „Einstellungen“, „Meine Gruppen“, „Gruppe anlegen“.
2. Name eintragen und **„Zur Verwendung freigegeben“** einschalten; erst dann finden andere die
   Gruppe. Ausschalten nimmt sie nur aus der Auswahl, bestehende Rechte bleiben.
3. Mitglieder über „Person suchen“ aufnehmen. Sie selbst sind verantwortlich, aber nicht
   automatisch Mitglied.

**Deaktivieren** lässt alle Rechte der Gruppe ruhen, „Reaktivieren“ stellt sie wieder her.
**Verantwortung abgeben** geht erst, wenn eine Nachfolge benannt ist. **Löschen** geht erst, wenn die
Gruppe nirgends mehr Rechte hat.

**Gut zu wissen:** Gruppen aus dem Verzeichnis oder dem Identitätsanbieter pflegt deren Quelle,
nicht OPAA.
