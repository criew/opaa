# Prompts verwenden

**Ziel:** Eine wiederkehrende Formulierung, etwa „Anhörung nach Hausstandard“, steht mit wenigen Angaben im Chat.
{: .kopf }

1. Im Eingabefeld am Anfang einer Zeile `/` tippen. Die Auswahl zeigt die Prompts, gruppiert nach
   Bibliothek.
2. Weitertippen sucht in Befehl, Titel und Beschreibung; einen Prompt wählen.
3. Hat der Prompt Variablen, fragt ein Formular die Werte ab, etwa Aktenzeichen oder Frist.
   Pflichtfelder sperren „Einsetzen“, ein Datum steht auf heute.
4. Der Text steht im Eingabefeld. Bei Bedarf anpassen und senden.

Ein Chip „`Prompt: <Titel>`“ am Eingabefeld zeigt die Herkunft und lässt sich entfernen. Im Verlauf
steht der Titel an der Frage.

**Gut zu wissen:**

- „Diesem Space sind keine Prompts zugeordnet“: Wer den Space kuratiert, kann eine
  Prompt-Bibliothek zuordnen ([Katalog nutzen](katalog.md#in-einem-space-verwenden)).
- Für Suche und Antwort macht ein Prompt keinen Unterschied; er ist nur Text.
- Wer welchen Prompt wie oft nutzt, wird weder protokolliert noch gezählt.
