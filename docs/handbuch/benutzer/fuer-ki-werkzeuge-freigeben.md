# Für externe KI-Werkzeuge freigeben

> **Wer:** *Verwalter* der Bibliothek, sobald die Systemverwaltung externe KI-Werkzeuge eingeschaltet hat.

Wer die Bibliothek lesen darf, kann sie danach in ein [Zugangstoken](zugangstoken.md)
aufnehmen und aus Werkzeugen wie OpenCode durchsuchen. Fundstellen verlassen damit OPAA und werden im fremden
Werkzeug mit dessen Modell weiterverarbeitet.

1. Detailseite der Bibliothek, Reiter „Freigaben“, Abschnitt „Externer Zugang“.
2. Unter „Freigabe bis“ ein Datum wählen.
3. „Für externe KI-Werkzeuge nutzbar“ einschalten.

Die Freigabe erlischt am gewählten Datum; vorher kommt eine Erinnerung per Mail, sofern der
Mailversand eingerichtet ist. Schalter aus nimmt
sie sofort für alle Tokens zurück.

**Gut zu wissen:** Ein Werkzeug sieht nie mehr als die Person, der das Token gehört.
