# Passwort ändern und Daten herunterladen

**Ziel:** Eine ZIP-Datei mit allem, was OPAA über Sie gespeichert hat, oder ein neues Passwort.
{: .kopf }

## Passwort ändern

Das geht nur bei lokalen Konten. Wer sich über einen Identitätsanbieter anmeldet, ändert das
Passwort dort.

1. „Einstellungen“, unter „Ihr Konto“ bei „Passwort“ auf „Ändern“.
2. Aktuelles und neues Passwort eingeben.

Alle anderen Sitzungen und Ihre [Zugangstokens](ki-werkzeug-einrichten.md#token-anlegen) enden.
Vergessen? „Passwort vergessen“ auf der Anmeldeseite, sonst hilft die Systemverwaltung.

## Eigene Daten herunterladen

1. „Einstellungen“, „Meine Daten“, „Daten herunterladen“.
2. Die Anmeldung bestätigen.
3. Der Browser speichert eine ZIP-Datei: eine lesbare Übersicht und je Kategorie eine
   maschinenlesbare Datei.

Dokumentinhalte, Passwörter und Tokens fehlen darin. Darüber gibt die oder der
Datenschutzbeauftragte Auskunft. Arbeitsmittel, Spaces und Gruppen, die Sie heute nicht mehr
sehen, stehen überall in der Auskunft als „(kein Leserecht)“ statt mit ihrem heutigen Namen, etwa
bei Favoriten, Zuordnungen zu Spaces, Chats, früheren Mitgliedschaften, Gruppenverantwortungen,
erteilten Rechten, Rechtehistorie, Nachfolgefällen, „Sicht als“-Befugnissen, Freigaben für
KI-Werkzeuge und verbundenen Bibliotheken. Einen Space sehen Sie, solange Sie Mitglied sind,
eine Gruppe, solange Sie Mitglied sind oder sie für Freigaben wählen können. Ihre heutigen
Mitgliedschaften stehen immer mit Namen da.

**Gut zu wissen:**

- Die Auskunft ist nur für Sie. Niemand darf verlangen, dass Sie sie vorlegen.
- Niemand sonst kann Ihre Auskunft auslösen, auch die Systemverwaltung nicht.
- Jeden Start meldet OPAA Ihnen, damit ein Start auffällt, den Sie nicht selbst ausgelöst haben.
