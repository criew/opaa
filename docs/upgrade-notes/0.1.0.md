`v0.1.0` ist das erste stabile Release. Eine neue Installation folgt dem Handbuch, Kapitel
Docker Compose bzw. Kubernetes.

**Wer einen Release-Kandidaten (`v0.1.0-rc.N`) betreibt, setzt neu auf.** Eine Datenmigration von den
Release-Kandidaten gibt es nicht: Datenbank und Originale werden verworfen, Bibliotheken neu
angelegt und indiziert. Der Ablauf steht im Handbuch, Kapitel Docker Compose, Abschnitt „Neu
aufsetzen statt aktualisieren“; für Kubernetes gilt er sinngemäß (Backend auf null Pods skalieren,
Datenbank leer neu anlegen, dann `helm upgrade`).
