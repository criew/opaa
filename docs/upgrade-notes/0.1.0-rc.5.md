Vor dem Update von `v0.1.0-rc.4`, für Kubernetes und Docker Compose gleichermaßen:

1. **Zeit für den neuen Index des Revisionsprotokolls einplanen.** Die Migration legt auf dem
   Revisionsprotokoll einen Index für die Ausleitung an ein Sicherheitsmonitoring an, über alle
   Monatspartitionen. Solange er gebaut wird, warten Vorgänge, die ins Protokoll schreiben, etwa
   Rechteänderungen und Anmeldungen der Verwaltung. Die Dauer hängt von der Größe des Protokolls
   ab; bei einem großen Bestand das Update in ein Wartungsfenster legen (Handbuch, Kapitel
   Überwachung und Fehlerbehebung, Abschnitt „Ausleitung an ein Sicherheitsmonitoring“).

Keine neue Pflicht-Variable und kein neuer Pflichtwert im Chart; die Ausleitung bleibt ab Werk aus.
